# Order management Website

## Tech Stack

- **Database**: SQL Server

- **Frontend**: React.js, React-Router, Redux, TypeScript, TailwindCSS

- **Backend**: Node.js, Express.js, TypeScript, zod, bcrypt, JWT

- **Security**: Cookies-Token, bcrypt

## About

- A secure web-based Order Management System that allows users to create, store, track, and manage orders.
- It supports viewing detailed order information and adding, updating, or deleting parties, statuses, and items.
- The application uses JWT authentication with secure cookies to protect access and ensure secure communication.
